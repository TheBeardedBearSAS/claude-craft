# Sprint BMAD Status

> **ALIAS** — This command redirects to `/sprint:status --bmad`. Use `/sprint:status --bmad` directly instead.

## Redirect

This command is an alias. Execute the following instead:

```
/sprint:status --bmad $ARGUMENTS
```

All arguments are forwarded. For example:

```
/sprint:bmad-status --verbose
```

is equivalent to:

```
/sprint:status --bmad --verbose
```
