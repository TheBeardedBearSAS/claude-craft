## Findings ouverts (a traiter)

### P1 — Dependency DoS : js-yaml / gray-matter (GHSA-h67p-54hq-rp68)

- **Packages** : `gray-matter ^4.0.3` → `js-yaml <=4.1.1`
- **Impact** : DoS quadratique via YAML merge keys avec aliases répétés (production dep, livré aux users)
- **Gate CI actuelle** : `npm audit --omit=dev --audit-level=high` — passe silencieusement car moderate
- **Actions** :
  1. Evaluer un remplacement de `gray-matter` ou pin via `overrides.js-yaml` dans `package.json`
  2. Abaisser le gate CI à `--audit-level=moderate`

### P1 — Hook templates : pattern $TOOL_INPUT (protect-files.json, quality-gate.json)

- **Templates concernés** : `.claude/templates/hooks/protect-files.json`, `.claude/templates/hooks/quality-gate.json`, `.claude/references/base/security.md:624`
- **Problème** : `echo '$TOOL_INPUT' | jq` est non-fonctionnel (`$TOOL_INPUT` n'est pas une variable env shell) → les hooks ne bloquent jamais
- **Fix** : Réécrire avec `INPUT=$(jq -r '.tool_input.file_path // .tool_input.command // empty')` depuis stdin (pattern de `block-dangerous-commands.json`)

### P2 — Agents permissions trop larges (chaos-engineer, observability-engineer)

- **Agents** : `chaos-engineer.md`, `observability-engineer.md`, `ralph-conductor.md`, `refactoring-specialist.md`, `mlops-engineer.md`, `tdd-coach.md`
- **Problème** : `disallowedTools: []` pour des agents avec accès Bash complet
- **Fix** : Ajouter des listes de deny pour les opérations destructives (`rm -rf`, `dd`, `mkfs`, `kubectl delete`)

### P2 — bats/bats:latest non épinglé dans CI

- **Fichier** : `.github/workflows/ci.yml` lignes 218, 221, 224, 227`
- **Problème** : tag mutable `latest` — incohérent avec le SHA-pinning de toutes les GitHub Actions
- **Fix** : Épingler sur `bats/bats:1.11.0` (variante Debian/Ubuntu) + commentaire Renovate

### P2 — Hook README : documentation des variables d'environnement incorrecte

- **Fichier** : `.claude/templates/hooks/README.md`
- **Problème** : Documente `$TOOL_INPUT` et `$TOOL_OUTPUT` comme variables d'environnement shell — factually incorrect
- **Fix** : Remplacer par la documentation du pattern stdin avec `cat` + `jq`

### P3 — SLSA over-claim dans SECURITY.md

- **Fichier** : `SECURITY.md`, `.claude/rules/11-security.md`
- **Etat actuel** : fixé dans `11-security.md` (L1 atteint, L2/L3 aspirationnels)
- **Suivi** : verifier et aligner `SECURITY.md` et `.github/workflows/sbom.yml` (signature cosign du SBOM lui-meme)
