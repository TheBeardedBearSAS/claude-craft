# Sobre

O Bear Craft é mantido por [The Bearded Bear](https://the-bearded-bear.com), fundador solo com forte envolvimento no ecossistema AFUP e Symfony francês.

O Bear Craft é publicado sob a licença MIT pela [The Bearded Bear SAS](https://github.com/TheBeardedBearSAS), a empresa francesa por trás do The Bearded Bear — a mesma pessoa, dois nomes: um para o produto, outro para a entidade jurídica.

Tem uma pergunta, um bug para relatar ou uma ideia? Abra uma issue no [GitHub](https://github.com/TheBeardedBearSAS/bear-craft/issues) — é a forma mais rápida de contatar o mantenedor.
