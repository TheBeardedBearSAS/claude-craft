# Acerca de

Bear Craft está mantenido por [The Bearded Bear](https://the-bearded-bear.com), fundador único con una fuerte implicación en el ecosistema AFUP y Symfony francés.

Bear Craft se publica bajo licencia MIT por [The Bearded Bear SAS](https://github.com/TheBeardedBearSAS), la empresa francesa detrás de The Bearded Bear — la misma persona, dos nombres: uno para el producto, otro para la entidad legal.

¿Tienes una pregunta, un error que reportar o una idea? Abre un issue en [GitHub](https://github.com/TheBeardedBearSAS/bear-craft/issues) — es la forma más rápida de contactar al mantenedor.
