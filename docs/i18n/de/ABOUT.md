# Über uns

Bear Craft wird von [The Bearded Bear](https://the-bearded-bear.com) gepflegt, einem Solo-Gründer mit starkem Engagement im französischen AFUP- und Symfony-Ökosystem.

Bear Craft wird unter der MIT-Lizenz von [The Bearded Bear SAS](https://github.com/TheBeardedBearSAS) veröffentlicht, dem französischen Unternehmen hinter The Bearded Bear — dieselbe Person, zwei Namen: einer für das Produkt, einer für die juristische Einheit.

Haben Sie eine Frage, einen Fehler zu melden oder eine Idee? Erstellen Sie ein Issue auf [GitHub](https://github.com/TheBeardedBearSAS/bear-craft/issues) — das ist der schnellste Weg, den Maintainer zu erreichen.
