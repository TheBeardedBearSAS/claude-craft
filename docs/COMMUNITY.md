## Contributing

We welcome contributions from everyone! Whether you're fixing a typo, adding a translation, or building a new feature.

**Get started**: [Contributing Guide](../CONTRIBUTING.md)

### First-Time Contributors

Looking to make your first contribution? Start here:

1. **Browse good-first-issue labels**: [Good First Issues](https://github.com/TheBeardedBearSAS/claude-craft/labels/good-first-issue)
2. **Fix documentation typos**: Improve our docs in any of our 5 languages (EN, FR, ES, DE, PT)
3. **Add missing translations**: Help translate docs to your language
4. **Write tests**: Improve test coverage for any module
5. **Fix lint warnings**: Clean up shellcheck or ESLint warnings

**See**: [First-Time Contributors Guide](../CONTRIBUTING.md#first-time-contributors--15-minute-onboarding)

## Getting Help

### Before Asking

1. Check the [documentation](../docs/)
2. Search [GitHub Issues](https://github.com/TheBeardedBearSAS/claude-craft/issues)
3. Search [GitHub Discussions](https://github.com/TheBeardedBearSAS/claude-craft/discussions)
4. Check [FAQ](./FAQ.md)

### How to Ask Good Questions

1. **Be specific**: Include error messages, versions, and steps to reproduce
2. **Provide context**: What are you trying to accomplish?
3. **Show your work**: What have you already tried?
4. **Use code blocks**: Format code and logs properly
5. **Be patient**: We're all volunteers
