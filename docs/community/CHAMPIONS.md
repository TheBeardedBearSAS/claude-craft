# Claude Craft Champions Program

Help shape the future of AI-first development.

---

## What is a Champion?

**Champions** are experienced Claude Craft users who:
- Contribute skills, agents, or workflow improvements
- Help other users in community channels
- Share case studies and production feedback
- Test new features before public release

---

## Benefits

### Recognition
- **Champion Badge** on GitHub profile and Discord
- Listed in `AUTHORS.md` and website
- Invitation to quarterly champion-only calls with maintainers

### Early Access
- Beta features 2 weeks before public release
- Direct feedback channel with core team
- Influence on roadmap priorities

### Community Impact
- Your skills/agents used by hundreds of teams
- Speaking opportunities at meetups/conferences
- Co-author blog posts on claude-craft.dev

---

## Eligibility

To become a Champion, demonstrate **one** of the following:

1. **Contributed 3+ accepted PRs** (skills, agents, rules, fixes)
2. **Helped 10+ users** in Discord/GitHub Discussions
3. **Published case study** with measurable impact (e.g., "Reduced QA time 40% with QA Recette")
4. **Maintained a stack reference** for 6+ months (e.g., Symfony reviewer)

---

## How to Apply

1. **Self-nominate:** Open an issue with title `[Champion Application] Your Name`
2. **Demonstrate eligibility:** Link to PRs, Discord threads, or case study
3. **Review:** Core team reviews within 7 days
4. **Onboarding:** If accepted, you'll receive Champion badge and invitation to private channel

**Application template:**

```markdown
## Champion Application

**Name:** Jane Doe  
**GitHub:** @janedoe  
**Discord:** janedoe#1234

### Contributions
- PR #123: Added Laravel skill for API generation
- PR #456: Fixed security rule for OWASP 2025
- Helped 15 users in #support channel (screenshots attached)

### Why I want to be a Champion
I've used Claude Craft on 3 production projects and want to help others succeed with AI-first TDD.

### Focus area
Laravel + Vue.js stack, QA automation
```

---

## Responsibilities

Champions are expected to:
- **Respond to mentions** in Discord/GitHub within 48 hours
- **Test beta features** and provide feedback within 1 week
- **Contribute quarterly** (1 PR, 5 support interactions, or 1 case study)
- **Follow Code of Conduct** (see CONTRIBUTING.md)

**Time commitment:** ~2-4 hours/month

---

## Champion Levels

### Bronze (Entry)
- 3+ contributions or 10+ support interactions
- Badge: 🥉 Bronze Champion
- Benefits: Early access, Discord badge

### Silver (Active)
- 6 months active + 10+ contributions
- Badge: 🥈 Silver Champion
- Benefits: Bronze + listed in AUTHORS.md + quarterly calls

### Gold (Core)
- 12 months active + 25+ contributions or 1 major feature
- Badge: 🥇 Gold Champion
- Benefits: Silver + co-author blog posts + speaking opportunities

## FAQs

### Can I be a Champion if I'm not a developer?
**Yes!** We need technical writers, testers, community managers, and case study authors.

### Do I need to be available 24/7?
**No.** 48-hour response time for mentions, ~2-4 hours/month commitment.

### Can I lose Champion status?
**Yes**, if inactive for 6 months without notice or Code of Conduct violation. You can reapply after addressing the issue.

### Is this paid?
**No**, this is a volunteer recognition program. Core maintainers are also volunteers.
