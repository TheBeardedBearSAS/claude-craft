# Verificação React

## Argumentos

$ARGUMENTS

O primeiro argumento é o eixo; o restante (por exemplo, o caminho de um projeto) é repassado sem alteração. Sem eixo, execute `all`.

| Eixo | Checklist a seguir |
|------|--------------------|
| `architecture` | `.claude/references/react/checks/architecture.md` |
| `code-quality` | `.claude/references/react/checks/code-quality.md` |
| `security` | `.claude/references/react/checks/security.md` |
| `testing` | `.claude/references/react/checks/testing.md` |
| `all` | `.claude/references/react/checks/all.md`: os 4 eixos e depois um relatório consolidado pontuado sobre 100 |

## MISSÃO

1. Leia o primeiro argumento. Se não corresponder a nenhum dos 5 eixos acima, liste-os com um exemplo (`/react:check security src/`) e pare.
2. Leia o arquivo de checklist desse eixo e siga-o passo a passo. Nesse arquivo, `$ARGUMENTS` designa os argumentos que vêm depois do eixo.
3. Produza o relatório no formato de saída definido pela checklist.

Exemplos: `/react:check architecture`, `/react:check testing ./app`, `/react:check all`.
