# Ruby on Rails Quality Tools

> Run every tool inside the container: `docker compose exec app <command>`. Rails 8 generates `bin/rubocop`, `bin/brakeman` and `bin/bundler-audit` binstubs; Rails 8.1 chains them in `bin/ci`.

## Quality Gate Overview

| Tool | Purpose | Gate |
|------|---------|------|
| **RuboCop** (`rubocop-rails-omakase`) | Style and lint | 0 offenses |
| **rubocop-rails / -performance / -rspec** | Extra cops | 0 offenses |
| **Brakeman** | Static security analysis | 0 unresolved warnings |
| **bundler-audit** | Gem CVE scan | 0 known vulnerabilities |
| **importmap audit** | JavaScript pin CVE scan | 0 known vulnerabilities |
| **SimpleCov** | Coverage | >= 80% |
| **Bullet / strict_loading** | N+1 detection | 0 N+1 in tests |
| **Steep / Sorbet** | Optional typing | 0 type errors when adopted |
| **Reek / Flog / Flay** | Smells, complexity, duplication | Advisory |
| **database_consistency** | Model vs schema consistency | Advisory or gate |
| **strong_migrations** | Unsafe migration prevention | Gate |

## RuboCop

### Default: rubocop-rails-omakase

Rails 8 ships an opinionated, low-noise configuration.

```yaml
# .rubocop.yml
inherit_gem:
  rubocop-rails-omakase: rubocop.yml
```

```bash
docker compose exec app bin/rubocop                  # Check
docker compose exec app bin/rubocop -a               # Auto-correct safe offenses
docker compose exec app bin/rubocop -A               # Include unsafe corrections (review the diff)
docker compose exec app bin/rubocop app/models       # Limit scope
docker compose exec app bin/rubocop -f github        # CI annotations
```

### Stricter Project Configuration

When the team wants more than the omakase defaults, add the community cops:

```yaml
# .rubocop.yml
inherit_gem:
  rubocop-rails-omakase: rubocop.yml

plugins:
  - rubocop-rails
  - rubocop-performance
  - rubocop-rspec          # only when using RSpec

AllCops:
  TargetRubyVersion: 4.0
  NewCops: enable
  Exclude:
    - "db/schema.rb"
    - "vendor/**/*"
    - "node_modules/**/*"
    - "bin/**/*"

Layout/LineLength:
  Max: 120

Metrics/MethodLength:
  Max: 10
  CountAsOne: ["array", "hash", "heredoc"]

Metrics/AbcSize:
  Max: 17

Metrics/CyclomaticComplexity:
  Max: 7

Metrics/ParameterLists:
  Max: 4

Style/FrozenStringLiteralComment:
  Enabled: true
  EnforcedStyle: always

Style/Documentation:
  Enabled: false

Rails/UnknownEnv:
  Environments: [development, test, production]
```

Verify the exact plugin syntax (`plugins:` vs `require:`) against the installed RuboCop version, since extension loading changed in recent releases.

### Handling Offenses

- Fix the code; disable a cop inline only with a reason:

```ruby
# rubocop:disable Metrics/MethodLength -- state machine kept flat for readability
def transition(event)
  # ...
end
# rubocop:enable Metrics/MethodLength
```

- Generate a todo file for legacy debt and shrink it over time:

```bash
docker compose exec app bin/rubocop --auto-gen-config --auto-gen-only-exclude --exclude-limit 1000
```

- Never commit an ever-growing `.rubocop_todo.yml`; review it each sprint

## Brakeman

Static analysis for Rails security issues (SQL injection, XSS, mass assignment, unsafe redirects, command injection, unsafe deserialisation).

```bash
docker compose exec app bin/brakeman                              # Full report
docker compose exec app bin/brakeman --no-pager --quiet
docker compose exec app bin/brakeman --exit-on-warn --exit-on-error   # CI gate
docker compose exec app bin/brakeman -f json -o brakeman.json
docker compose exec app bin/brakeman -I                           # Interactively ignore
```

### Ignoring False Positives

`config/brakeman.ignore` is generated by `brakeman -I`:

```json
{
  "ignored_warnings": [
    {
      "fingerprint": "...",
      "note": "Value comes from an allow-listed constant, reviewed 2026-11-01"
    }
  ]
}
```

Every ignored warning requires a written justification (`note`) and a reviewer. Treat new warnings as build failures.

## bundler-audit and Dependency Hygiene

```bash
docker compose exec app bin/bundler-audit                   # Scan Gemfile.lock
docker compose exec app bundle exec bundler-audit check --update
docker compose exec app bin/importmap audit                 # Pinned JS packages
docker compose exec app bundle outdated --strict
```

`bin/bundler-audit` is wired in `config/ci.rb` by default in Rails 8.1. Complement it with Dependabot or Renovate for automated update PRs, and a nightly scheduled workflow so new advisories surface without a code change.

```yaml
# .github/dependabot.yml
version: 2
updates:
  - package-ecosystem: bundler
    directory: "/"
    schedule:
      interval: weekly
    open-pull-requests-limit: 5
  - package-ecosystem: github-actions
    directory: "/"
    schedule:
      interval: weekly
```

Supply chain practices (OWASP A03:2025): commit `Gemfile.lock`, review new gems, enable MFA on RubyGems for owned gems, generate an SBOM (CycloneDX) at build time, scan the image with Trivy or Grype.

## Coverage: SimpleCov

```ruby
# test/test_helper.rb or spec/rails_helper.rb, first lines
require "simplecov"
SimpleCov.start "rails" do
  enable_coverage :branch
  minimum_coverage line: 80, branch: 70
  minimum_coverage_by_file 60
  add_filter %w[/config/ /db/ /test/ /spec/]
end
```

Coverage is enforced by SimpleCov exiting non-zero when thresholds are missed. Publish `coverage/` as a CI artifact.

## Performance and Data Quality

### N+1 Detection

```ruby
# config/environments/development.rb and test.rb
config.after_initialize do
  Bullet.enable = true
  Bullet.raise = true if Rails.env.test?
  Bullet.rails_logger = true
end

# Alternatively, Rails built-in strict loading
config.active_record.strict_loading_by_default = true
config.active_record.action_on_strict_loading_violation = :log
```

### strong_migrations

```ruby
# Gemfile (development, test)
gem "strong_migrations"
```

```ruby
class AddIndexToOrders < ActiveRecord::Migration[8.1]
  disable_ddl_transaction!

  def change
    add_index :orders, :status, algorithm: :concurrently
  end
end
```

`strong_migrations` blocks unsafe operations (non-concurrent indexes, column removals still read by running code) with an actionable message.

### database_consistency

```bash
docker compose exec app bundle exec database_consistency
```

Detects missing indexes behind validations, missing foreign keys, and `null: false` mismatches between models and the schema.

## Complexity and Smells

```bash
docker compose exec app bundle exec reek app/services          # Code smells
docker compose exec app bundle exec flog -g app/models         # Complexity (ABC)
docker compose exec app bundle exec flay app                   # Duplication
```

Thresholds (project rule 05): methods < 10 lines (limit 20), cognitive complexity < 7 (limit 10), cyclomatic complexity < 5 (limit 10), nesting depth <= 3, <= 4 parameters. RuboCop's `Metrics/*` cops approximate these in CI.

## Static Typing (Optional)

### Steep with RBS

```bash
docker compose exec app bundle exec rbs collection install
docker compose exec app bundle exec steep check
```

```ruby
# Steepfile
target :app do
  signature "sig"
  check "app/services"
  library "activerecord"
end
```

### Sorbet

```bash
docker compose exec app bundle exec srb init
docker compose exec app bundle exec srb tc
```

Adopt one typing approach, start with services and value objects, and enforce it in CI. Do not mix systems in the same directory.

## Local CI: bin/ci (Rails 8.1)

```ruby
# config/ci.rb
CI.run do
  step "Setup", "bin/setup --skip-server"
  step "Style: Ruby", "bin/rubocop"
  step "Security: Gem audit", "bin/bundler-audit"
  step "Security: Importmap vulnerability audit", "bin/importmap audit"
  step "Security: Brakeman code analysis", "bin/brakeman --quiet --no-pager --exit-on-warn --exit-on-error"
  step "Tests: Rails", "bin/rails test"
  step "Tests: Seeds", "env RAILS_ENV=test bin/rails db:seed:replant"
end
```

```bash
docker compose exec app bin/ci
```

Add project steps for RSpec, system tests, Steep/Sorbet, `zeitwerk:check` and `database_consistency`.

## GitHub Actions Pipeline

```yaml
name: CI
on:
  pull_request:
  push:
    branches: [main]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { bundler-cache: true }
      - run: bin/rubocop -f github

  security:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { bundler-cache: true }
      - run: bin/brakeman --no-pager --exit-on-warn --exit-on-error
      - run: bin/bundler-audit
      - run: bin/importmap audit

  test:
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:17
        env: { POSTGRES_PASSWORD: postgres }
        ports: ["5432:5432"]
        options: >-
          --health-cmd="pg_isready" --health-interval=10s
          --health-timeout=5s --health-retries=5
    env:
      RAILS_ENV: test
      DATABASE_URL: postgres://postgres:postgres@localhost:5432/test
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { bundler-cache: true }
      - run: bin/rails db:test:prepare test test:system
```

Pin actions to commit SHAs for supply chain integrity.

## Pre-commit Hooks

```yaml
# lefthook.yml
pre-commit:
  parallel: true
  commands:
    rubocop:
      glob: "*.{rb,rake}"
      run: docker compose exec -T app bin/rubocop --force-exclusion {staged_files}
    brakeman:
      glob: "{app,config,lib}/**/*.rb"
      run: docker compose exec -T app bin/brakeman -q --no-pager --exit-on-warn
```

## Scoring Alignment

The `/ruby:check` audit maps tools to axes:

| Axis | Tool evidence |
|------|---------------|
| Architecture | `zeitwerk:check`, Bullet/strict loading, database_consistency |
| Code quality | RuboCop, Reek/Flog, Steep/Sorbet |
| Security | Brakeman, bundler-audit, importmap audit |
| Testing | SimpleCov, test suite results |

## Quality Checklist

- [ ] `bin/rubocop` returns 0 offenses
- [ ] `bin/brakeman` returns 0 unresolved warnings
- [ ] `bin/bundler-audit` and `bin/importmap audit` are clean
- [ ] SimpleCov enforces >= 80%
- [ ] N+1 detection active in test
- [ ] `strong_migrations` active
- [ ] `bin/ci` passes locally and CI runs the same steps
- [ ] Dependabot or Renovate configured
- [ ] Ignored warnings and RuboCop disables carry a reason
