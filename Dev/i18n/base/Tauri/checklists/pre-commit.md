# Pre-Commit Checklist - Tauri v2

## Quick Validation Before Each Commit

All commands run in Docker (`docker compose exec app ...`). Keep one script or `make ci` target that chains the steps below so the local gate equals the CI gate. GUI launches (`tauri dev`) and E2E runs happen on the host OS or a CI runner with a display, not in this gate.

### Code Quality (Rust)

- [ ] Formatting clean (`cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check`)
- [ ] Clippy clean with warnings denied (`cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --all-features -- -D warnings`)
- [ ] New `#[allow(...)]` justified, scoped to one item (prefer `#[expect(..., reason = "...")]`)
- [ ] No `dbg!`, `println!`, `todo!` left behind; no commented-out code
- [ ] No `unwrap()` / `expect()` added in command, event or setup paths
- [ ] Functions < 10 lines (limit 20), nesting <= 3, parameters <= 4

### Code Quality (Frontend)

- [ ] Type check passes (`npx tsc --noEmit`)
- [ ] ESLint or Biome passes with zero warnings
- [ ] New `invoke` calls live in the typed IPC wrapper module, with explicit argument and return types
- [ ] No `any` or `@ts-ignore` added at the IPC boundary

### Tests

- [ ] Rust tests pass (`cargo test --manifest-path src-tauri/Cargo.toml --all-features`)
- [ ] Frontend tests pass (`npx vitest run`), `clearMocks()` in `afterEach` for IPC mocks
- [ ] New behavior has tests written first (Red, Green, Refactor)
- [ ] New commands have a mock-runtime test (`tauri::test`) and a `mockIPC` test on the wrapper
- [ ] Bug fixes include a regression test that failed before the fix
- [ ] Coverage maintained at 80% or higher (Rust and frontend)
- [ ] No `#[ignore]`, `.skip` or `.only` added without a ticket

### Security

- [ ] Capability diff reviewed: every new permission is needed, scoped (`allow` / `deny`) and attached to the right window only
- [ ] No broad fs, shell or http scope added (no whole-home, no wildcard hosts, no arbitrary executables)
- [ ] CSP unchanged or tightened; no `unsafe-eval`; `withGlobalTauri` still off
- [ ] No signing key, `.env`, certificate, keystore or provisioning profile staged; updater private key stays in the CI secret store
- [ ] Command arguments (paths, ids, URLs) validated in Rust, not only in the UI
- [ ] `cargo audit` and `cargo deny check` pass; `npm audit --omit=dev --audit-level=moderate` passes

### Configuration and Dependencies

- [ ] `tauri`, `tauri-build`, `@tauri-apps/cli`, `@tauri-apps/api` and plugin crates/packages are on the same 2.x line
- [ ] New plugin has its Rust crate, npm package (if any), `.plugin(...)` registration (with `#[cfg(desktop)]` when desktop-only) and permissions
- [ ] `Cargo.lock` and the JS lockfile committed and consistent (`cargo build --locked`, `npm ci`)
- [ ] `gen/schemas/` regenerated by the build, not hand-edited
- [ ] Version bumped consistently in `tauri.conf.json`, `Cargo.toml` and `package.json` when releasing

### Documentation and Git

- [ ] README / docs updated when setup, commands or permissions changed
- [ ] CHANGELOG updated if applicable
- [ ] Commit message follows Conventional Commits (`feat(files): add export command`)
- [ ] Commit is atomic; branch up to date with `main`
- [ ] No unrelated files staged (`git status`, `git diff --staged`)

## Automated Validation

### CI gate script

```bash
#!/usr/bin/env bash
# scripts/ci.sh - same steps locally and in CI
set -euo pipefail

cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --all-features -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml --all-features
npx tsc --noEmit
npx eslint . --max-warnings 0
npx vitest run --coverage
cargo deny --manifest-path src-tauri/Cargo.toml check
```

Run it in the container:

```bash
docker compose exec app ./scripts/ci.sh
```

### Git pre-commit hook (Lefthook)

```yaml
# lefthook.yml
pre-commit:
  parallel: true
  commands:
    fmt:
      glob: "*.rs"
      run: docker compose exec -T app cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check
    clippy:
      glob: "*.{rs,toml}"
      run: docker compose exec -T app cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
    types:
      glob: "*.{ts,tsx,vue,svelte}"
      run: docker compose exec -T app npx tsc --noEmit
pre-push:
  commands:
    tests:
      run: docker compose exec -T app sh -c 'cargo test --manifest-path src-tauri/Cargo.toml && npx vitest run'
    deny:
      run: docker compose exec -T app cargo deny --manifest-path src-tauri/Cargo.toml check
```

Hooks are requirements, CLAUDE.md is a suggestion.

## Final Check

If any box is unchecked, do not commit. Fix first, then re-run `./scripts/ci.sh`.
