# Bear Craft — Vite

Vite 8.3: Framework-agnostic build tool: vanilla JS/TS, library authoring, multi-page apps. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-vite@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-vite:check-library-build` — Validate build.lib output and vite-plugin-dts .d.ts generation for a Vite library
- `/bear-vite:check` — Vite-Audit nach Achse: architecture, code-quality, security, testing oder all (bewertete Gesamtauswertung)
- `/bear-vite:scaffold-project` — Scaffold a new Vite project (vanilla-ts or lit-ts template) or a library skeleton

## Agents

`vite-reviewer`
