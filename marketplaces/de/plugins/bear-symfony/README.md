# Bear Craft — Symfony / PHP

Symfony / PHP 8.1 / PHP 8.4+: PHP backend with Clean Architecture, DDD, API Platform. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-symfony@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-symfony:api-endpoint` — API Platform Endpoint erstellen
- `/bear-symfony:check` — Symfony-Audit nach Achse: architecture, code-quality, security, testing oder all (bewertete Gesamtauswertung)
- `/bear-symfony:generate-command` — Symfony-Befehl generieren
- `/bear-symfony:generate-crud` — Vollständigen CRUD generieren
- `/bear-symfony:migration-plan` — Datenbankmigrationsplanung
- `/bear-symfony:optimize-doctrine` — Doctrine-Abfragen optimieren
