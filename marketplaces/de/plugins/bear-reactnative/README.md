# Bear Craft — React Native

React Native 0.88: Mobile JS/TS New Architecture (JSI, TurboModules, Fabric). Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-reactnative@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-reactnative:app-size` — React Native Anwendungsgrößenanalyse
- `/bear-reactnative:check` — React Native-Audit nach Achse: architecture, code-quality, security, testing oder all (bewertete Gesamtauswertung)
- `/bear-reactnative:deep-link` — React Native Deep Linking Konfiguration
- `/bear-reactnative:generate-screen` — React Native Screen Generierung
- `/bear-reactnative:native-module` — React Native Native Module Erstellungsleitfaden
- `/bear-reactnative:store-prepare` — React Native Store Veröffentlichungs-Checkliste
