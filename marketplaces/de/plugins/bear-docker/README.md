# Bear Craft — Docker

Docker: Dockerfile, Compose, CI/CD image pipelines and debugging, with specialist agents.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-docker@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-docker:architecture` — Vollständige Docker-Architektur
- `/bear-docker:cicd-pipeline` — Docker CI/CD Pipeline
- `/bear-docker:compose-setup` — Docker Compose Einrichtung
- `/bear-docker:debug` — Docker Diagnose
- `/bear-docker:optimize` — Dockerfile-Optimierung

## Agents

`docker-architect`, `docker-cicd`, `docker-compose`, `docker-debug`, `docker-dockerfile`
