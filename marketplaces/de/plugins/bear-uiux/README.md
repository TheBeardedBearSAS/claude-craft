# Bear Craft — UI/UX

UI/UX/accessibility audits, component specs, design tokens, user flows and DESIGN.md.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-uiux@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-uiux:a11y-audit` — WCAG 2.2 AAA Barrierefreiheit-Audit
- `/bear-uiux:a11y-component` — Barrierefreiheits-Spezifikation für Komponenten
- `/bear-uiux:audit` — Vollständiges UI/UX/Barrierefreiheit-Audit
- `/bear-uiux:component-spec` — Vollständige Komponenten-Spezifikation UI/UX/A11y
- `/bear-uiux:design-tokens` — Design-Tokens-Definition
- `/bear-uiux:generate-design-md` — Generiert eine DESIGN.md im Projektstamm aus dem Bear Craft Template + Analyse vorhandener UI-Quellen (Tailwind, Tokens, CSS).
- `/bear-uiux:user-flow` — Benutzerfluss-Design
