# Bear Craft — Flutter / Dart

Flutter / Dart 3.47 / Dart 3.13: Mobile Dart with BLoC v9, Riverpod 3, Material 3, Impeller. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-flutter@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-flutter:analyze-performance` — Flutter Performance-Analyse
- `/bear-flutter:check` — Flutter-Audit nach Achse: architecture, code-quality, security, testing oder all (bewertete Gesamtauswertung)
- `/bear-flutter:generate-feature` — Génération Feature Flutter Complète
- `/bear-flutter:generate-widget` — Génération Widget Flutter avec Tests
- `/bear-flutter:golden-update` — Mise à jour Golden Tests
- `/bear-flutter:localization-check` — Vérification des Traductions
