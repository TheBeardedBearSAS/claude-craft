# Bear Craft — Tauri

Tauri 2.12: Desktop & mobile apps: Rust core + web frontend, capabilities/permissions, plugins, signed updater. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-tauri@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-tauri:check` — Tauri-v2-Audit nach Achse: architecture, code-quality, security, testing oder all (bewerteter Gesamtbericht)

## Agents

`tauri-reviewer`
