# Bear Craft — Gates

Quality gates: PRD, tech spec, backlog, sprint, story, alignment, commit, merge and release.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-gate@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-gate:check` — Beliebiges Quality Gate ausführen: Dokument-Gates (PRD, Tech Spec, Backlog, Sprint, Story, Alignment), Code-Gates (commit, merge, release), den Gesamtbericht oder einen Phasen-Checkpoint
