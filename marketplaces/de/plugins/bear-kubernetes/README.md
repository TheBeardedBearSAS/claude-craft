# Bear Craft — Kubernetes

Kubernetes: architecture, deployment setup, security audit and troubleshooting.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-kubernetes@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-kubernetes:architecture` — Vollstandige Kubernetes-Architektur entwerfen
- `/bear-kubernetes:debug` — Kubernetes-Probleme anhand von Symptomen diagnostizieren
- `/bear-kubernetes:deploy-setup` — GitOps-Deployment-Pipeline fur Kubernetes einrichten
- `/bear-kubernetes:optimize` — Kubernetes-Ressourcennutzung und -kosten optimieren
- `/bear-kubernetes:security-audit` — Kubernetes-Sicherheitslage prufen

## Agents

`kubernetes-architect`, `kubernetes-debug`, `kubernetes-deployment`, `kubernetes-monitoring`, `kubernetes-security`
