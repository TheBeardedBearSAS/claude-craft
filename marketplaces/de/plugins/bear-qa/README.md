# Bear Craft — QA

Browser acceptance testing (QA Recette) with regression registry and TDD bug fixing.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-qa@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-qa:fix` — Automatisierte Fehlerbehebung aus QA Recette Sitzungen
- `/bear-qa:recette` — Automatisierte Akzeptanztests mit Claude in Chrome
- `/bear-qa:regression` — QA Recette Regressionstest-Register anzeigen und verwalten
- `/bear-qa:status` — QA Recette Sitzungsstatus und Fortschritt anzeigen oder Berichte erzeugen (--report)
- `/bear-qa:tdd` — Bugfix im TDD/BDD-Modus
