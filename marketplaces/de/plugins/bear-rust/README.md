# Bear Craft — Rust / Axum

Rust / Axum 0.8 / Rust 1.99: Backend Rust 1.99 (edition 2024) with Axum 0.8, Tokio, SQLx, cargo-nextest. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-rust@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-rust:check` — Rust/Axum-Audit nach Achse: architecture, code-quality, security, testing oder all (bewerteter Gesamtbericht)

## Agents

`rust-reviewer`
