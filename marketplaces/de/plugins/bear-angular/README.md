# Bear Craft — Angular

Angular 22: Frontend TS with Signals, Zoneless, httpResource, Signal Forms. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-angular@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-angular:check` — Angular-Audit nach Achse: architecture, code-quality, security, testing oder all (bewertete Gesamtauswertung)
- `/bear-angular:generate-component` — Generate Angular standalone component with tests

## Agents

`angular-reviewer`
