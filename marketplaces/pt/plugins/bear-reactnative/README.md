# Bear Craft — React Native

React Native 0.88: Mobile JS/TS New Architecture (JSI, TurboModules, Fabric). Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-reactnative@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-reactnative:app-size` — Análise do Tamanho da Aplicação React Native
- `/bear-reactnative:check` — Auditoria React Native por eixo: architecture, code-quality, security, testing, ou all (agregado com pontuação)
- `/bear-reactnative:deep-link` — Comando: Implementar Deep Linking
- `/bear-reactnative:generate-screen` — Geração de Tela React Native
- `/bear-reactnative:native-module` — Guia de Criação de Módulo Nativo React Native
- `/bear-reactnative:store-prepare` — Lista de Verificação para Publicação React Native nas Lojas
