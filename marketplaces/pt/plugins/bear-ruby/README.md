# Bear Craft — Ruby / Rails

Ruby / Rails 8.1 / Ruby 4.0: Backend Ruby 4.0 with Rails 8.1, Hotwire, Solid Queue, RSpec/Minitest. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-ruby@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-ruby:check` — Auditoria Ruby/Rails por eixo: architecture, code-quality, security, testing, ou all (agregado com pontuação)

## Agents

`ruby-reviewer`
