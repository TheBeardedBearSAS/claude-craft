# Bear Craft — Kubernetes

Kubernetes: architecture, deployment setup, security audit and troubleshooting.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-kubernetes@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-kubernetes:architecture` — Projetar arquitetura Kubernetes completa
- `/bear-kubernetes:debug` — Diagnosticar problemas do Kubernetes a partir de sintomas
- `/bear-kubernetes:deploy-setup` — Configurar pipeline de deployment GitOps para Kubernetes
- `/bear-kubernetes:optimize` — Otimizar uso de recursos e custos do Kubernetes
- `/bear-kubernetes:security-audit` — Auditoria de postura de segurança do Kubernetes

## Agents

`kubernetes-architect`, `kubernetes-debug`, `kubernetes-deployment`, `kubernetes-monitoring`, `kubernetes-security`
