# Bear Craft — UI/UX

UI/UX/accessibility audits, component specs, design tokens, user flows and DESIGN.md.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-uiux@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-uiux:a11y-audit` — Auditoria de Acessibilidade WCAG 2.2 AAA
- `/bear-uiux:a11y-component` — Especificação de Acessibilidade de Componente
- `/bear-uiux:audit` — Auditoria Completa UI/UX/Acessibilidade
- `/bear-uiux:component-spec` — Especificação Completa de Componente UI/UX/A11y
- `/bear-uiux:design-tokens` — Definição de Design Tokens
- `/bear-uiux:generate-design-md` — Gera um DESIGN.md na raíz do projeto a partir do template do Bear Craft + análise de fontes UI existentes (Tailwind, tokens, CSS).
- `/bear-uiux:user-flow` — Design de Fluxo de Usuário
