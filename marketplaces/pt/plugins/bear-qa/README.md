# Bear Craft — QA

Browser acceptance testing (QA Recette) with regression registry and TDD bug fixing.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-qa@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-qa:fix` — Correcao automatizada de bugs identificados pela QA Recette
- `/bear-qa:recette` — Testes de aceitacao automatizados com Claude in Chrome
- `/bear-qa:regression` — Ver e gerenciar o registro de testes de regressao QA Recette
- `/bear-qa:status` — Mostrar o status e progresso das sessões QA Recette, ou gerar relatórios (--report)
- `/bear-qa:tdd` — Correção de Bug em Modo TDD/BDD
