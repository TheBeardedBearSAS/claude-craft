# Bear Craft — Flutter / Dart

Flutter / Dart 3.47 / Dart 3.13: Mobile Dart with BLoC v9, Riverpod 3, Material 3, Impeller. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-flutter@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-flutter:analyze-performance` — Análise de Performance Flutter
- `/bear-flutter:check` — Auditoria Flutter por eixo: architecture, code-quality, security, testing, ou all (agregado com pontuação)
- `/bear-flutter:generate-feature` — Geração de Feature Flutter Completa
- `/bear-flutter:generate-widget` — Geração de Widget Flutter com Testes
- `/bear-flutter:golden-update` — Atualização dos Golden Tests
- `/bear-flutter:localization-check` — Verificação de Traduções
