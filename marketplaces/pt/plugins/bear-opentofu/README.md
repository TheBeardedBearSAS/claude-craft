# Bear Craft — OpenTofu

OpenTofu: infrastructure-as-code architecture, deployment setup, security audit and debugging.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-opentofu@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-opentofu:architecture` — Projetar arquitetura completa de IaC com OpenTofu
- `/bear-opentofu:debug` — Diagnosticar problemas de estado e drift do OpenTofu
- `/bear-opentofu:deploy-setup` — Configurar pipeline de CI/CD para OpenTofu
- `/bear-opentofu:optimize` — Otimização de custos e análise de recursos OpenTofu
- `/bear-opentofu:security-audit` — Auditar postura de segurança do OpenTofu

## Agents
