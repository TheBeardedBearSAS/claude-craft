# Bear Craft — PHP

PHP 8.5: Backend PHP 8.5 with PSR-12, PHPStan, Pest PHP. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-php@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-php:check` — Auditoria PHP por eixo: architecture, code-quality, security, testing, ou all (agregado com pontuação)

## Agents

`php-reviewer`
