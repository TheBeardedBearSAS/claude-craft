# Bear Craft — Gates

Quality gates: PRD, tech spec, backlog, sprint, story, alignment, commit, merge and release.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-gate@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-gate:check` — Executar qualquer quality gate: gates de documentos (PRD, tech spec, backlog, sprint, story, alinhamento), gates de código (commit, merge, release), o relatório completo ou um checkpoint de fase
