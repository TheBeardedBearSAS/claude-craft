# Bear Craft — Kubernetes

Kubernetes: architecture, deployment setup, security audit and troubleshooting.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-kubernetes@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-kubernetes:architecture` — Diseñar una arquitectura Kubernetes completa
- `/bear-kubernetes:debug` — Diagnosticar problemas de Kubernetes a partir de síntomas
- `/bear-kubernetes:deploy-setup` — Configurar un pipeline de despliegue GitOps para Kubernetes
- `/bear-kubernetes:optimize` — Optimizar el uso de recursos y los costes en Kubernetes
- `/bear-kubernetes:security-audit` — Auditoría de la postura de seguridad de Kubernetes

## Agents

`kubernetes-architect`, `kubernetes-debug`, `kubernetes-deployment`, `kubernetes-monitoring`, `kubernetes-security`
