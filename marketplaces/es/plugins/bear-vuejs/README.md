# Bear Craft — Vue.js

Vue.js 3.5+: Frontend JS/TS with Composition API, Pinia, Vitest. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-vuejs@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-vuejs:check` — Auditoría Vue.js por eje: architecture, code-quality, security, testing, o all (agregado con puntuación)
- `/bear-vuejs:generate-component` — Generate a Vue.js component with TypeScript, tests, and Storybook

## Agents

`vuejs-reviewer`
