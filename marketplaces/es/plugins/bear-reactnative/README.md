# Bear Craft — React Native

React Native 0.88: Mobile JS/TS New Architecture (JSI, TurboModules, Fabric). Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-reactnative@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-reactnative:app-size` — Análisis del Tamaño de Aplicación React Native
- `/bear-reactnative:check` — Auditoría React Native por eje: architecture, code-quality, security, testing, o all (agregado con puntuación)
- `/bear-reactnative:deep-link` — Configuración de Deep Linking en React Native
- `/bear-reactnative:generate-screen` — Generación de Screen en React Native
- `/bear-reactnative:native-module` — Guía de Creación de Módulo Nativo en React Native
- `/bear-reactnative:store-prepare` — Lista de Verificación para Publicación en Tiendas de React Native
