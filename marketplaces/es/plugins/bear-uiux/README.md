# Bear Craft — UI/UX

UI/UX/accessibility audits, component specs, design tokens, user flows and DESIGN.md.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-uiux@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-uiux:a11y-audit` — Auditoría de Accesibilidad WCAG 2.2 AAA
- `/bear-uiux:a11y-component` — Especificación de Accesibilidad de Componente
- `/bear-uiux:audit` — Auditoría Completa UI/UX/Accesibilidad
- `/bear-uiux:component-spec` — Especificación Completa de Componente UI/UX/A11y
- `/bear-uiux:design-tokens` — Definición de Design Tokens
- `/bear-uiux:generate-design-md` — Genera un DESIGN.md en la raíz del proyecto a partir del template de Bear Craft + análisis de fuentes UI existentes (Tailwind, tokens, CSS).
- `/bear-uiux:user-flow` — Diseño de Flujo de Usuario
