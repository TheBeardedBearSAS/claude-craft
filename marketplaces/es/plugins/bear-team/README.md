# Bear Craft — Team

Parallel multi-agent teams: audit, security review and sprint delivery.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-team@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-team:audit` — Equipo de Auditoria Completa - Auditoria paralela multi-tecnologia con subagentes (Agent Teams opcional)
- `/bear-team:delivery` — Equipo de Entrega - Ciclo de vida completo del sprint (redaccion + implementacion) con subagentes (Agent Teams opcional)
- `/bear-team:security` — Equipo de Revision de Seguridad - Auditoria de seguridad paralela multi-dimension con subagentes (Agent Teams opcional)
