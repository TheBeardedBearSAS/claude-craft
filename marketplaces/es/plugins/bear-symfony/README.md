# Bear Craft — Symfony / PHP

Symfony / PHP 8.1 / PHP 8.4+: PHP backend with Clean Architecture, DDD, API Platform. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-symfony@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-symfony:api-endpoint` — Creación Endpoint API Platform
- `/bear-symfony:check` — Auditoría Symfony por eje: architecture, code-quality, security, testing, o all (agregado con puntuación)
- `/bear-symfony:generate-command` — Generación de Comando Symfony
- `/bear-symfony:generate-crud` — Generación CRUD Completo
- `/bear-symfony:migration-plan` — Planificación de Migración de Base de Datos
- `/bear-symfony:optimize-doctrine` — Optimización de Consultas Doctrine
