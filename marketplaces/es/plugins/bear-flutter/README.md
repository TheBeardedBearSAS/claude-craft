# Bear Craft — Flutter / Dart

Flutter / Dart 3.47 / Dart 3.13: Mobile Dart with BLoC v9, Riverpod 3, Material 3, Impeller. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-flutter@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-flutter:analyze-performance` — Análisis de Rendimiento Flutter
- `/bear-flutter:check` — Auditoría Flutter por eje: architecture, code-quality, security, testing, o all (agregado con puntuación)
- `/bear-flutter:generate-feature` — Generación Feature Flutter Completa
- `/bear-flutter:generate-widget` — Generación Widget Flutter con Tests
- `/bear-flutter:golden-update` — Actualización Golden Tests
- `/bear-flutter:localization-check` — Verificación de Traducciones
