# Bear Craft — Laravel

Laravel 13.x / PHP 8.3+: PHP backend with Actions, Pest 5, Sanctum, AI SDK, Passkey. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-laravel@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-laravel:check` — Auditoría Laravel por eje: architecture, code-quality, security, testing, o all (agregado con puntuación)
- `/bear-laravel:generate-controller` — Generate a Laravel controller following best practices

## Agents

`laravel-reviewer`
