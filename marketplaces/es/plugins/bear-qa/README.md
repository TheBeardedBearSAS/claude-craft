# Bear Craft — QA

Browser acceptance testing (QA Recette) with regression registry and TDD bug fixing.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-qa@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-qa:fix` — Correccion automatizada de bugs identificados por QA Recette
- `/bear-qa:recette` — Pruebas de aceptacion automatizadas con Claude in Chrome
- `/bear-qa:regression` — Ver y gestionar el registro de tests de regresion QA Recette
- `/bear-qa:status` — Mostrar el estado y progreso de las sesiones QA Recette, o generar informes (--report)
- `/bear-qa:tdd` — Corrección de Bug en Modo TDD/BDD
