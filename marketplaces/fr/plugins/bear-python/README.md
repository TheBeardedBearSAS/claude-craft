# Bear Craft — Python

Python 3.15 / 3.14+: Backend with FastAPI, Pydantic, free-threading, JIT. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-python@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-python:async-check` — Vérification Patterns Async Python
- `/bear-python:check` — Audit Python par axe : architecture, code-quality, security, testing, ou all (agrégat noté)
- `/bear-python:dependency-audit` — Audit des Dépendances Python
- `/bear-python:generate-endpoint` — Génération Endpoint FastAPI
- `/bear-python:generate-model` — Génération Model SQLAlchemy
- `/bear-python:type-coverage` — Vérification Couverture des Types Python
