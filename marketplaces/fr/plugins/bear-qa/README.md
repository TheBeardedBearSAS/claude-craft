# Bear Craft — QA

Browser acceptance testing (QA Recette) with regression registry and TDD bug fixing.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-qa@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-qa:fix` — Correction automatisee des bugs identifies par la QA Recette
- `/bear-qa:recette` — Tests d'acceptance automatises avec Claude in Chrome
- `/bear-qa:regression` — Voir et gerer le registre de tests de regression QA Recette
- `/bear-qa:status` — Afficher le statut et la progression des sessions QA Recette, ou générer des rapports (--report)
- `/bear-qa:tdd` — Correction de Bug en Mode TDD/BDD
