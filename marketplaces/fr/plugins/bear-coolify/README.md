# Bear Craft — Coolify

Coolify: self-hosted PaaS setup, deployment, backups and debugging.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-coolify@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-coolify:backup` — Configure and manage Coolify backups
- `/bear-coolify:debug` — Diagnose Coolify deployment issues
- `/bear-coolify:deploy` — Deploy application to Coolify
- `/bear-coolify:optimize` — Optimize Coolify deployment
- `/bear-coolify:setup` — Initialize project for Coolify deployment

## Agents

`coolify-architect`, `coolify-debug`, `coolify-deployment`, `coolify-monitoring`
