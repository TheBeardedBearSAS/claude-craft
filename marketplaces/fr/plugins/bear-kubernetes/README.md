# Bear Craft — Kubernetes

Kubernetes: architecture, deployment setup, security audit and troubleshooting.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-kubernetes@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-kubernetes:architecture` — Concevoir une architecture Kubernetes complète
- `/bear-kubernetes:debug` — Diagnostiquer des problèmes Kubernetes à partir des symptômes
- `/bear-kubernetes:deploy-setup` — Configurer un pipeline de déploiement GitOps pour Kubernetes
- `/bear-kubernetes:optimize` — Optimiser l'utilisation des ressources et les coûts Kubernetes
- `/bear-kubernetes:security-audit` — Audit de la posture de sécurité Kubernetes

## Agents

`kubernetes-architect`, `kubernetes-debug`, `kubernetes-deployment`, `kubernetes-monitoring`, `kubernetes-security`
