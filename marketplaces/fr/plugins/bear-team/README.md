# Bear Craft — Team

Parallel multi-agent teams: audit, security review and sprint delivery.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-team@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-team:audit` — Équipe d'Audit Complet - Audit multi-technologie parallèle par sous-agents (Agent Teams en option)
- `/bear-team:delivery` — Équipe de Livraison - Cycle de vie complet du sprint (rédaction + implémentation) par sous-agents (Agent Teams en option)
- `/bear-team:security` — Équipe de Revue de Sécurité - Audit de sécurité multi-dimension parallèle par sous-agents (Agent Teams en option)
