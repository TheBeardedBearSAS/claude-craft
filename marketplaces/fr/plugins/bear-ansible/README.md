# Bear Craft — Ansible

Ansible: automation architecture, deployment setup, security audit and debugging.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-ansible@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-ansible:architecture` — Design complete Ansible automation architecture
- `/bear-ansible:debug` — Diagnose Ansible playbook issues from symptoms
- `/bear-ansible:deploy-setup` — Setup CI/CD pipeline for Ansible automation
- `/bear-ansible:optimize` — Optimize Ansible performance and playbook quality
- `/bear-ansible:security-audit` — Audit Ansible security posture

## Agents

`ansible-architect`, `ansible-debug`, `ansible-deployment`, `ansible-quality`, `ansible-security`
