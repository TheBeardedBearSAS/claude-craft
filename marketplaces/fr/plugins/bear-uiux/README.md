# Bear Craft — UI/UX

UI/UX/accessibility audits, component specs, design tokens, user flows and DESIGN.md.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-uiux@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-uiux:a11y-audit` — Audit Accessibilité WCAG 2.2 AAA
- `/bear-uiux:a11y-component` — Spécification Accessibilité Composant
- `/bear-uiux:audit` — Audit Complet UI/UX/Accessibilité
- `/bear-uiux:component-spec` — Spécification Complète Composant UI/UX/A11y
- `/bear-uiux:design-tokens` — Définition Design Tokens
- `/bear-uiux:generate-design-md` — Génère un DESIGN.md à la racine du projet à partir du template Bear Craft + analyse des sources UI existantes (Tailwind, tokens, CSS).
- `/bear-uiux:user-flow` — Conception Parcours Utilisateur
