# Bear Craft — Symfony / PHP

Symfony / PHP 8.1 / PHP 8.4+: PHP backend with Clean Architecture, DDD, API Platform. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-symfony@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-symfony:api-endpoint` — Création Endpoint API Platform
- `/bear-symfony:check` — Audit Symfony par axe : architecture, code-quality, security, testing, ou all (agrégat noté)
- `/bear-symfony:generate-command` — Génération Commande Symfony
- `/bear-symfony:generate-crud` — Génération CRUD Complet
- `/bear-symfony:migration-plan` — Planification Migration Base de Données
- `/bear-symfony:optimize-doctrine` — Optimisation Requêtes Doctrine
