# Bear Craft — React

React 19.3 + Compiler 1.0: Frontend JS/TS with Hooks, Compiler 1.0, Server Components. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-react@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-react:accessibility-check` — Audit Accessibilité React
- `/bear-react:bundle-analyze` — Analyse du Bundle React
- `/bear-react:check` — Audit React par axe : architecture, code-quality, security, testing, ou all (agrégat noté)
- `/bear-react:generate-component` — Génération Composant React
- `/bear-react:generate-hook` — Génération Custom Hook React
- `/bear-react:storybook-story` — Génération Story Storybook
