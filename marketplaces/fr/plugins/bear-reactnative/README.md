# Bear Craft — React Native

React Native 0.88: Mobile JS/TS New Architecture (JSI, TurboModules, Fabric). Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-reactnative@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-reactnative:app-size` — Analyse Taille Application React Native
- `/bear-reactnative:check` — Audit React Native par axe : architecture, code-quality, security, testing, ou all (agrégat noté)
- `/bear-reactnative:deep-link` — Configuration Deep Linking React Native
- `/bear-reactnative:generate-screen` — Génération Screen React Native
- `/bear-reactnative:native-module` — Guide Création Module Natif React Native
- `/bear-reactnative:store-prepare` — Checklist Publication Store React Native
