# Bear Craft — OpenTofu

OpenTofu: infrastructure-as-code architecture, deployment setup, security audit and debugging.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-opentofu@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-opentofu:architecture` — Design complete OpenTofu IaC architecture
- `/bear-opentofu:debug` — Diagnose OpenTofu state issues and drift
- `/bear-opentofu:deploy-setup` — Setup CI/CD pipeline for OpenTofu
- `/bear-opentofu:optimize` — OpenTofu cost optimization and resource analysis
- `/bear-opentofu:security-audit` — Audit OpenTofu security posture
