# Bear Craft — C# / .NET

C# / .NET 10 LTS / C# 14: Backend with Clean Architecture, CQRS, MediatR, EF Core. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-csharp@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-csharp:check` — C#/.NET audit by axis: architecture, code-quality, security, testing, or all (scored aggregate)
- `/bear-csharp:generate-feature` — Generate a complete feature with Clean Architecture structure

## Agents

`csharp-reviewer`
