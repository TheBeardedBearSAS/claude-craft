# Bear Craft — React

React 19.3 + Compiler 1.0: Frontend JS/TS with Hooks, Compiler 1.0, Server Components. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-react@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-react:accessibility-check` — Accessibility Audit
- `/bear-react:bundle-analyze` — Bundle Size Analysis
- `/bear-react:check` — React audit by axis: architecture, code-quality, security, testing, or all (scored aggregate)
- `/bear-react:generate-component` — Generate React Component
- `/bear-react:generate-hook` — Generate Custom Hook
- `/bear-react:storybook-story` — Generate Storybook Story

## Agents
