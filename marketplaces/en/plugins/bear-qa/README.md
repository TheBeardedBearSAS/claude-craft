# Bear Craft — QA

Browser acceptance testing (QA Recette) with regression registry and TDD bug fixing.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-qa@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/bear-qa:fix` — Automated bug fixing from QA Recette sessions
- `/bear-qa:recette` — Automated acceptance testing with Claude in Chrome
- `/bear-qa:regression` — View and manage QA Recette regression test registry
- `/bear-qa:status` — Show QA Recette session status and progress, or generate reports (--report)
- `/bear-qa:tdd` — Bug Fix in TDD/BDD Mode
