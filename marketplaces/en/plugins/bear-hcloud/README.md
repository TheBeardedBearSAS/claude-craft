# Bear Craft — Hetzner Cloud

Hetzner Cloud (hcloud): architecture, deployment setup, security audit and debugging.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-hcloud@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-hcloud:architecture` — Design complete Hetzner Cloud infrastructure architecture
- `/bear-hcloud:debug` — Diagnose Hetzner Cloud infrastructure issues from symptoms
- `/bear-hcloud:deploy-setup` — Setup CI/CD pipeline for Hetzner Cloud deployments
- `/bear-hcloud:optimize` — Optimize Hetzner Cloud cost and performance
- `/bear-hcloud:security-audit` — Audit Hetzner Cloud security posture

## Agents

`hcloud-architect`, `hcloud-cost`, `hcloud-debug`, `hcloud-deployment`, `hcloud-security`
