# Bear Craft — Vercel

Vercel 65.14.0: Framework-agnostic deployment platform: vercel.json, Functions (Node.js/Fluid Compute), ISR, Cron Jobs, Storage. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-vercel@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-vercel:check` — Vercel audit by axis: architecture, code-quality, security, testing, or all (scored aggregate)
- `/bear-vercel:deploy-config` — Detect the project's Vercel deployment shape and generate or validate a tailored vercel.json

## Agents

`vercel-reviewer`
