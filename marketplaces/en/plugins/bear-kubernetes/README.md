# Bear Craft — Kubernetes

Kubernetes: architecture, deployment setup, security audit and troubleshooting.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install bear-kubernetes@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 10.0.0.

## Commands

- `/bear-kubernetes:architecture` — Design complete Kubernetes architecture
- `/bear-kubernetes:debug` — Diagnose Kubernetes issues from symptoms
- `/bear-kubernetes:deploy-setup` — Setup GitOps deployment pipeline for Kubernetes
- `/bear-kubernetes:optimize` — Optimize Kubernetes resource usage and costs
- `/bear-kubernetes:security-audit` — Kubernetes security posture audit

## Agents

`kubernetes-architect`, `kubernetes-debug`, `kubernetes-deployment`, `kubernetes-monitoring`, `kubernetes-security`
