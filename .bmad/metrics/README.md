# Sprint Metrics Storage

This directory stores historical sprint metrics data.

## File Format

- `sprint-{id}.json` — Full metrics snapshot for a sprint
- `burndown-{id}.json` — Daily burndown data for a sprint

## Usage

Metrics are automatically generated by:
- `/project:metrics` — Creates `sprint-{id}.json`
- `/project:burndown` — Creates/updates `burndown-{id}.json`

## Retention

- Keep metrics for at least 5 sprints for trend analysis
- Archive older sprints to `archive/` subdirectory
