# Bear Craft — UI/UX

UI/UX/accessibility audits, component specs, design tokens, user flows and DESIGN.md.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install uiux@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/uiux:a11y-audit` — WCAG 2.2 AAA Accessibility Audit
- `/uiux:a11y-component` — Component Accessibility Specification
- `/uiux:audit` — Complete UI/UX/Accessibility Audit
- `/uiux:component-spec` — Complete Component Specification UI/UX/A11y
- `/uiux:design-tokens` — Design Tokens Definition
- `/uiux:generate-design-md` — Generate a DESIGN.md at the project root from the Bear Craft template + analysis of existing UI sources (Tailwind, tokens, CSS).
- `/uiux:user-flow` — User Flow Design
