# Bear Craft — WordPress

WordPress 7.1: Plugins & block themes: blocks (block.json), REST API, WP-CLI, WPCS/PHPStan, wp-env; WooCommerce as opt-in skill. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install wordpress@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/wordpress:check` — WordPress audit by axis: architecture, code-quality, security, testing, or all (scored aggregate)

## Agents

`wordpress-reviewer`

## Skills

`woocommerce`
