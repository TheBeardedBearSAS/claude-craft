# Bear Craft — Tauri

Tauri 2.12: Desktop & mobile apps: Rust core + web frontend, capabilities/permissions, plugins, signed updater. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install tauri@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/tauri:check` — Tauri v2 audit by axis: architecture, code-quality, security, testing, or all (scored aggregate)

## Agents

`tauri-reviewer`

## About

Part of [Bear Craft](https://github.com/TheBeardedBearSAS/bear-craft) by The Bearded Bear. Each plugin is generated from the framework installers (`npm run plugins:generate`); do not edit it by hand.
