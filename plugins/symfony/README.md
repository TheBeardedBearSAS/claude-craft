# Bear Craft — Symfony / PHP

Symfony / PHP 8.1 / PHP 8.4+: PHP backend with Clean Architecture, DDD, API Platform. Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install symfony@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/symfony:api-endpoint` — Création Endpoint API Platform
- `/symfony:check` — Symfony audit by axis: architecture, code-quality, security, testing, or all (scored aggregate)
- `/symfony:generate-command` — Génération Commande Symfony
- `/symfony:generate-crud` — Génération CRUD Complet
- `/symfony:migration-plan` — Planification Migration Base de Données
- `/symfony:optimize-doctrine` — Optimization Requêtes Doctrine
