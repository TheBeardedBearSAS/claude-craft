# Bear Craft — React Native

React Native 0.88: Mobile JS/TS New Architecture (JSI, TurboModules, Fabric). Audit and generation commands, reviewer agent and stack skills.

## Installation

Inside Claude Code:

```
/plugin marketplace add TheBeardedBearSAS/bear-craft
/plugin install reactnative@bear-craft
```

Requires Claude Code 2.1.325 or later. Version 9.4.0.

## Commands

- `/reactnative:app-size` — React Native Application Size Analysis
- `/reactnative:check` — React Native audit by axis: architecture, code-quality, security, testing, or all (scored aggregate)
- `/reactnative:deep-link` — React Native Deep Linking Configuration
- `/reactnative:generate-screen` — React Native Screen Generation
- `/reactnative:native-module` — React Native Native Module Creation Guide
- `/reactnative:store-prepare` — React Native Store Publication Checklist
