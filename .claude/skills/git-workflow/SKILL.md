## Quick Reference

- **Commits**: `<type>(<scope>): <description>`
- **Types**: feat, fix, docs, style, refactor, perf, test, build, ci, chore
- **Branches**: `feature/`, `fix/`, `refactor/`, `docs/`
- **Max branch life**: 3 days
- **Review**: Required before merge
