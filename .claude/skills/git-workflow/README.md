# Git Workflow

Universal Git workflow guidelines with GitHub Flow and Conventional Commits.

Part of [Claude-Craft](https://github.com/TheBeardedBearSAS/claude-craft) -- AI-assisted development framework for Claude Code.

## Installation

Copy this directory to your project's `.claude/skills/` directory:

```bash
cp -r git-workflow/ your-project/.claude/skills/git-workflow/
```

## What's Included

- `SKILL.md` -- Skill definition with triggers and quick reference
- `REFERENCE.md` -- Comprehensive Git workflow guidelines covering GitHub Flow, conventional commits, branching, pull requests, and code review

## Covers

- GitHub Flow -- main branch always deployable, feature branches, PRs
- Conventional Commits -- `<type>(<scope>): <description>` format
- Branch naming -- `feature/`, `fix/`, `refactor/`, `docs/`
- Pull request templates -- checklists for code, tests, docs, security
- Code review process -- reviewer checklists, constructive feedback

## Technology Agnostic

This skill provides universal Git workflow practices applicable to any project regardless of language or framework. Works with GitHub, GitLab, Bitbucket, or any Git hosting platform.
