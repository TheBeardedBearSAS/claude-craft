# Internationalisation (i18n) — Quick Reference

Claude Craft supporte **5 langues** : `en` (référence), `fr`, `es`, `de`, `pt`.

## Structure des fichiers i18n

| Répertoire | Contenu |
|-----------|---------|
| `Dev/i18n/<lang>/` | Règles et références techniques par langue |
| `Infra/i18n/<lang>/` | Guides infrastructure |
| `Project/i18n/<lang>/` | Templates BMAD et gestion de projet |
| `docs/guides/<lang>/` | Guides utilisateur (10 guides par langue) |

## Seuil de parité de taille

Le script `scripts/verify-i18n-parity.sh` vérifie deux niveaux :

| Vérification | Type | Seuil |
|---|---|---|
| Nombre de fichiers | **Bloquant** | 100% parité avec `en` |
| Taille des fichiers | **Bloquant** (depuis v8.8.2) | **0.80** (fichier traduit ≥ 80% taille en) |

> **Depuis v8.8.2 :** la dette i18n historique étant entièrement résorbée (gap 0),
> le script bloque par défaut sur la taille (`STRICT_SIZE=1`, `I18N_PARITY_STRICT=1`).
> Tout nouveau fichier sous 0.80 est désormais une régression qui fait échouer la CI.

```bash
# Vérifier la parité (bloquant sur count ET sur taille < 0.80)
bash scripts/verify-i18n-parity.sh

# Mode permissif (PR transitionnelle uniquement — désactive le blocage taille)
STRICT_SIZE=0 I18N_PARITY_STRICT=0 bash scripts/verify-i18n-parity.sh
```

Le rapport CSV des fichiers sous seuil est généré dans `audit/phases/i18n-gap.csv`.

## Ajouter une nouvelle locale

Voir `docs/guides/en/ADDING-NEW-LOCALE.md` — guide complet en 5 étapes :
1. Ajouter le code dans `cli/lib/constants.js`
2. Créer les dossiers `Dev/i18n/<lang>/`, `Infra/`, `Project/`
3. Traduire les fichiers depuis l'anglais (délégable à un agent)
4. Vérifier la parité avec `bash scripts/verify-i18n-parity.sh`
5. Ajouter le filtre dans `.github/workflows/i18n-parity.yml`

## Détection automatique de locale

Le CLI détecte `process.env.LANG` / `process.env.LC_ALL` et pré-sélectionne la langue :
`fr_*` → `fr` | `es_*` → `es` | `de_*` → `de` | `pt_*` → `pt` | autres → `en`
