# Vérification Angular

## Arguments

$ARGUMENTS

Le premier argument est l'axe ; le reste (par exemple un chemin de projet) est transmis tel quel. Sans axe, exécutez `all`.

| Axe | Checklist à suivre |
|-----|--------------------|
| `architecture` | `.claude/references/angular/checks/architecture.md` |
| `code-quality` | `.claude/references/angular/checks/code-quality.md` |
| `security` | `.claude/references/angular/checks/security.md` |
| `testing` | `.claude/references/angular/checks/testing.md` |
| `all` | `.claude/references/angular/checks/all.md` : les 4 axes, puis un rapport consolidé noté sur 100 |

## MISSION

1. Lisez le premier argument. S'il ne correspond à aucun des 5 axes ci-dessus, listez-les avec un exemple (`/angular:check security src/`) et arrêtez-vous.
2. Lisez le fichier de checklist de cet axe et suivez-le étape par étape. Dans ce fichier, `$ARGUMENTS` désigne les arguments qui suivent l'axe.
3. Produisez le rapport au format de sortie défini par la checklist.

Exemples : `/angular:check architecture`, `/angular:check testing ./app`, `/angular:check all`.
